## The story

> She sold everything, kept the dog.

Six words, one whole life in them: everything gone — the house, the
things, the past — except the one companion that mattered. The turn is
in the last three words: what she kept says what she lost was never
the point.

## Run it

```sh
python3 main.py
```

This writes the story to `/output/entry.txt` — exactly six words,
34 characters, valid UTF-8.
